# Expansion Followup — تجارب بحثية إضافية على مدرسة Trend Following (XAUUSD)

مرحلة بحثية مستقلة ومحدودة: **فقط** مدرسة Trend Following، على نفس بيانات وإعدادات الاختبار الأصلي المجمّد، عبر محرك التشغيل الإنتاجي الحقيقي نفسه. لا تعديل على أي محرك أو مدرسة أخرى، لا تداول حقيقي، ولا استخدام لأي معلومة مستقبلية.

## الأسئلة التي تجيب عنها هذه التجارب

1. هل يحسن قصر التداول على حالة **EXPANSION** (ER20 ≥ 0.30) الأداء؟ (تجربة 1)
2. ما الأداء الحقيقي لـ **Trend Pullback Continuation** وحدها دون Donchian Breakout؟ (تجربة 2)
3. هل نتائج **الأحد / ساعة 23:00 UTC** ميزة حقيقية أم مصادفة؟ (تجربة 3 — A/B/C/D + استكشافي E)
4. هل **الجمع بين الفلاتر** يحسن الأداء فعلًا؟ (تجربة 4)
5. أين تربح الاستراتيجية وأين تخسر؟ (تحليلات شهرية/أسبوعية/ساعية/حالة السوق/الاتجاه/المدة)

## المبدأ المنهجي الحاسم

كل بوابة (Gate) هنا **بوابة دخول جديدة فقط تُركّب وقت التشغيل (runtime-only monkey-patch)** على `TrendFollowingStrategy.evaluate` داخل عملية البحث — **لا يُعدّل أي ملف في المنصة**. شروط الدخول/الخروج الأصلية، إدارة الصفقة، محرك المخاطر، حساب حجم العقود، التكاليف (سبريد 0.25$ / انزلاق 2 نقطة / عمولة 7$/لوط/جهة، بلا سواب) — كلها **مجمدة كما هي** في الاختبار الأصلي. الصفقة المفتوحة تُدار حتى الخروج بغض النظر عن البوابة.

- بوابة التوسع تستخدم **دالة المحرك نفسها** `efficiency_ratio(bars, 20)` على نفس نافذة الشموع M15 المغلقة التي يراها المحرك (≤600 شمعة = BarService.MAX_BUFFER) — بلا أي lookahead.
- بوابة Pullback-only تعطّل إعداد DONCHIAN_BREAKOUT بحياد اسم `donchian_channel` داخل evaluate الأصلية — قواعد Pullback تعمل دون أي تعديل.
- بوابات التوقيت تعمل على **وقت القرار UTC الحقيقي** (= لحظة الدخول: تنفيذ فوري على تيك الإغلاق).

## المتغيرات العشرة

| المتغير | البوابة |
|---|---|
| `baseline_repro` | بلا بوابة — يجب أن يطابق التشغيل الأصلي صفقة بصفقة (محرك حتمي) |
| `exp1_expansion_only` | دخول فقط عند ER20 ≥ 0.30 |
| `exp2_pullback_only` | تعطيل Donchian Breakout، بقية القواعد أصلية |
| `exp3a_sunday_only` | دخول أيام الأحد فقط (UTC) |
| `exp3b_h23_only` | دخول ساعة 23 UTC فقط (23:00–23:59) |
| `exp3c_no_sunday` | كل الأيام ما عدا الأحد |
| `exp3d_no_h23` | كل الساعات ما عدا 23 |
| `exp3e_sunday_h23` | الأحد وساعة 23 معاً (**استكشافي** — عينة صغيرة جداً) |
| `exp4a_exp_pullback` | توسع + Pullback فقط |
| `exp4b_exp_pb_timing` | توسع + Pullback + أفضل فلتر توقيت من التجربة 3 |

قاعدة اختيار «أفضل توقيت» **مسبقة التسجيل**: أعلى صافي ربح بين متغيرات التجربة 3 (كسر التعادل: أعلى PF) — تُوثّق في `runs/exp4b_selection.json` قبل تشغيل exp4b. الاختيار نفسه risk ما بعد-الاختبار (multiple comparisons) ويُقرأ بحذر.

## طريقة التشغيل

```bash
# متطلبات: python3 + pandas/pyarrow/SQLAlchemy<2.1/PyYAML/numpy (+ arabic-reshaper/python-bidi للرسوم)
# التشغيل الكامل (تسلسلي، عملية منفصلة لكل متغير لعزل الذاكرة):
bash research/expansion_followup/run_all.sh

# أو متغير واحد:
python3 research/expansion_followup/run_experiments.py --variant exp1_expansion_only

# اختبار سريع (شهران):
python3 research/expansion_followup/run_experiments.py --variant exp1_expansion_only --smoke

# بعد انتهاء التشغيلات:
python3 research/expansion_followup/verify_experiments.py   # تحقق برمجي شامل
python3 research/expansion_followup/analyze_experiments.py  # المقاييس والتحليلات والCSV/JSON
python3 research/expansion_followup/make_charts.py          # الرسوم البيانية
```

كل تشغيل ينتج في `runs/<variant>/`: `trades.csv`, `equity_curve.csv`, `decisions.csv`, `run_summary.json`, `gate_params.json`, `console.log`.

## ملاحظات تعريفية مهمة

- تصنيف النظام (EXPANSION/CONSOLIDATION) في هذا التحليل يستخدم **دلالة الإغلاق الصحيحة** (آخر شمعة M15 **المغلقة** وقت القرار) — وتعليم الأصل في `tf_postprocess.py` كانت تدخل الشمعة المفتوحة حديثاً (فرق طفيف موثق). بوابات التوسع نفسها عملت منذ البداية على الشموع المغلقة فقط.
- Sharpe محسوب على عوائد رأس المال اليومية (آخر قيمة لكل يوم) × √252، بلا سعر خالي من المخاطر؛ مضلل عندما يكون عدد الصفقات صغيراً — يُقرأ مع عدد الصفقات دائماً.
- Bootstrap: 10,000 إعادة سحب (seed=42) لفترات ثقة 95% للتوقع لكل صفقة. اختبارات التبديل العشوائي (permutation) ثنائية الجانب بمقدار 10,000 خلط.
- تعدد التجارب: عشرة متغيرات وعشرات الأجزاء الزمنية تعني ظهور 1–2 نتيجة «مهمة إحصائياً» بالمصادفة عند p<0.05 بشكل متوقع — أي نتيجة صغيرة العينة تُعامل كاستكشافية لا كدليل.
