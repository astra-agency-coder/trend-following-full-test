## 1) ما بُني فعلياً (ويعمل)

نظام Backend كامل (~8,900 سطر كود مصدري + ~1,670 سطر اختبارات، 92 ملف
بايثون) يعمل من البداية للنهاية: قراءة بيانات ← سياق سوق ← تقييم ست مدارس ←
قرار هجين ← مخاطر ← صفقة افتراضية ← إدارة وإغلاق ← تسجيل شامل ← إشعارات.

### المحركات

| المحرك | الحالة | أبرز ما نُفّذ |
|---|---|---|
| **Market Data Engine** | ✅ كامل | واجهة Provider موحدة (قراءة فقط)، MT5 adapter بدون أي دالة تنفيذ، ReplayProvider حتمي، مدقق tick/bar (قديم/متصالب/OHLC)، كشف فجوات الشموع، منع الشمعة غير المكتملة (`closed_bars(as_of=)`)، شاشة صحة البيانات مع أحداث DEGRADED/RECOVERED، حل اسم الرمز حسب الوسيط (XAUUSD/XAUUSDm/GOLD...)، تخزين الشموع بقييد فريد |
| **Market Context Engine** | ✅ كامل | الاتجاه (ADX+ER+MA alignment)، التقلب (ATR ratio إلى متوسطه المتحرك)، النشاط (tick volume proxy — موسوم صراحة أنه ليس سيولة عالمية)، سيولة proxy من السبريد، بنية السوق (Swings بتأكيد، BOS/CHoCH بالإغلاق، انضغاط/تمدد، تسلسل HH-HL)، جلسات IANA مع DST تلقائي (مفحوص على تبديلات مارس/أكتوبر 2026)، مستويات مرجعية (High/Low اليوم السابق والجلسة)، لقطة كاملة مخزنة بكل مكوناتها |
| **المدارس الست** | ✅ 5 مفعّلة + 1 معطّلة موثقة | SMC/ICT (3 أنماط: Sweep Reversal بتعريف EQ tolerance، BOS Continuation، FVG Retrace + Displacement وOrder Blocks كمفاهيم موصوفة)، Wyckoff (نطاق بجودة، Spring/Upthrust، SOS/SOW، مرحلة مقدّرة لا مفروضة)، Trend (Donchian + Pullback مع خروج ATR Trailing بلا TP ثابت)، Mean Reversion (z-score + تأكيد شمعة، RSI مساعد فقط، هدف المتوسط)، Breakout (انضغاط + كسر إغلاق + Retest مع حارسي الامتداد والسبريد)، Order Flow (معطّلة: لا يوجد مصدر Depth/Delta حقيقي للذهب الفوري — الواجهة جاهزة للربط لاحقاً) |
| **Hybrid Decision Engine** | ✅ كامل | خط أنابيب: أهلية (B) ← ترتيب حتمي (C) ← اختيار (D). ثماني حالات قرار تميّد سبب عدم الدخول. لا إجماع مطلوب، مرشح واحد مؤهل يكفي. مكونات درجة منفصلة (سلامة النمط/ملاءمة السياق/التوقيت/قابلية التنفيذ/جودة خطة المخاطر). منع التضارب عبر opportunity_key. Anti-churn (hysteresis) لا يؤخر دخولاً صحيحاً |
| **Risk Engine** | ✅ كامل | حجم المركز من مواصفات الرمز (tick value/contract)، تقريب للأسفل دائماً + إعادة تحقق الخطر، حدود (إجمالي مفتوح، مواقع متزامنة، لكل مدرسة، نفس الاتجاه، نفس التجمع)، قاطع خسارة يومي 2% |
| **Paper Trading Engine** | ✅ كامل | آلة حالة بمنتقِلات موثقة، تعبئة Bid/Ask صحيحة حسب الجانب + انزلاق معاكس دائماً، تنفيذ SL عند الفجوة على أول سعر متاح، SL يتضيّق فقط، عمولة (ذهاب/عودة) + سواب اختياري، P/L صافي وR multiple، Break-Even عند 1R، إدارة الصفقة تبقى لمدرستها الأصلية |
| **Shadow Tracking** | ✅ كامل | تسجيل الفرص غير المختارة بنفس قواعد دخولها المقترحة (لا سعر أفضل بأثر رجعي)، MFE/MAE، نتائج مختومة CENSORED عند انتهاء الصلاحية، عزل تام عن ربح المحفظة، تصنيف LOW_SAMPLE/SUFFICIENT |
| **Audit & Research DB** | ✅ كامل | 24 جدولاً بكل القيود المطلوبة (FK، UNIQUE، NOT NULL، Numeric للأسعار)، سجل append-only بسلسلة SHA-256 (كشف التلاعب مفحوص)، إصدارات للإعدادات والاستراتيجيات مرتبطة بكل قرار/صفقة، UTC في كل مكان + توقيت محلي وجلسة، تصدير CSV/JSON لكل الجداول |
| **Performance Analytics** | ✅ كامل | كل المقاييس المطلوبة (Win Rate, PF, Expectancy, Expectancy-R, Max DD على أساس الصفقات المغلقة، متوسط المدة، التكاليف...) + تقسيم بالاستراتيجية/الجلسة/الساعة/اليوم/الاتجاه + جودة الـ Router (نسبة NO_TRADE، تبديلات الاختيار) + أداء الفرص المرفوضة + علم LOW_SAMPLE يمنع تفسير العينات الصغيرة |
| **Telegram Bot** | ✅ كامل | 12 أمراً (status/market/open/today/week/performance/strategies/decision/health/logs/pause/resume + start/help)، إشعارات عربية غنية بمعرّفات قابلة للبحث، Outbox بمفتاح فريد + إعادة محاولة تراجعية (1/5/15/60/240 د) + استسلام بعد 5، تفويض بالمعرّف الرقمي + حد معدل، كل أمر مُدقَّق، أوامر تشغيلية فقط (لا Buy/Sell) |
| **التشغيل 24/7** | ✅ كامل | systemd unit مع Restart=always وتقوية أمان، start/stop/restart/healthcheck/maintenance scripts، تدوير سجلات (داخلي 20MB×10 + gzip للأقدم)، فحص مساحة القرص، الأسرار من .env فقط مع مسح من السجلات، استعادة الصفقات والمفاتيح بعد إعادة التشغيل (مفحوص) |

## 2) قرارات هندسية موثقة (نقاط غير محسومة في الوثيقة)

| النقطة | القرار | المسوّغ |
|---|---|---|
| قاعدة البيانات | SQLAlchemy + SQLite تطوير/اختبار، PostgreSQL إنتاج | نفس الكود والاختبارات على الخلفين؛ لا خادم PostgreSQL في بيئة البناء هذه |
| Migrations | عدّاد SQL مدمج + create_all | يعمل على الخلفين؛ ترقية Alembic كاملة متاحة لاحقاً دون تغيير الواجهة |
| مصدر بيانات الاختبار | مولّد LCG ببذور ثابتة | قابلية إعادة إنتاج كاملة بلا شبكة؛ موسوم صراحة أنه ليس بيانات سوق حقيقية |
| عمر tick في الـ backtest | `step_seconds × 10` بدل لا نهائي | يسمح بقفزات الساعة الافتراضية مع بقاء كشف الانقطاع الحقيقي فعّالاً |
| Trailing بدل TP للمدرسة الاتجاهية | خروج ATR Trailing 2.0 | تلبية "لا تجعل TP ثابتاً إجبارياً"؛ سياسة موثقة في العقد وليست غياب TP |
| تعطيل Order Flow | `DISABLED_DATA_UNAVAILABLE` | حجم tick وسيط واحد لا يقيس Delta/Depth؛ النظام لا يزوّر بيانات |
| Phase في Wyckoff | "تقدير" مسجل بثقة | المراحل الأصلية اجتهادية؛ النظام لا يقدمها كحقيقة |
| حجم العمولة/السواب | قيم افتراضية تجريبية مع علم `INCOMPLETE` | لا بيانات وسيط فعلية؛ لا تُمرر بصمت كأنها حقيقية |

## 4) ما لم يُنفّذ (صراحة كاملة)

1. **تعليق الأوامر المعلّقة (Pending LIMIT/STOP orders) في المحفظة الافتراضية**:
   جدول `paper_orders` موجود والنموذج مدعوم، لكن التدفق الحالي يدخل بأسعار
   السوق فقط (كل المدارس الحالية تقترح MARKET). يُفعّل عند إضافة مدرسة
   بأسلوب الدخول المعلق.
2. **الإغلاق الجزئي (Partial Close)**: `PaperTrade.remaining_volume_lots`
   وحالة `PARTIALLY_CLOSED` موجودة في النموذج، ولا توجد سياسة مدرسة تطلبها
   حالياً — البنية جاهزة دون مسار تنفيذ مستخدم.
3. **تقارير Telegram المجدولة تلقائياً** (اليومية/الأسبوعية): التوليد
   (`generate_report.py`) والقوالب والأوامر الفورية تعمل؛ جدولتها cron
   في `DEPLOYMENT_VPS.md` بدل مؤقت داخلي — قرار توثيقي لتقليل التعقيد.
4. **Alembic migrations كملفات إصدار**: عدّاد SQL يعمل الآن؛ الترقية
   الموصى بها للإنتاج الدائم طويل الأمد.

هذه البنود **موثقة كبنود مستقبلية** وليست placeholder يُدّعى أنها مكتملة؛
لا توجد في الكود أي دالة وهمية تُعامل كمكتملة.

## 5) ضمانات القواعد غير القابلة للتجاوز

- **Paper فقط**: رفض صريح عند الإقلاع إن فُعّل مسار حقيقي (اختبار)، لا
  `order_send` في أي مكان (grep آلي في الاختبارات)، adapter بلا أي دالة تنفيذ.
- **Rule-Based**: لا استيراد لأي مكتبة AI/ML في الكود؛ `enable_ai` مرفوض من
  المدقق.
- **لا Martingale/Grid/توسط**: مرفوضة من مدقق الإعدادات (اختبار).
- **لا lookahead**: مفحوص من ثلاث زوايا (مؤشرات/تقييمات/تِكات).
- **لا أرقام عشوائية في الاستراتيجيات**: كل العشوائية محصورة في مولّد بيانات
  الاختبار والانزلاق المحاكى ببذرة ثابتة.
- **عزل الأعطال**: انهيار مدرسة يُسجل ERROR ويستمر الباقي (اختبار).
