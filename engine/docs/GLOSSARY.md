# مسرد المصطلحات — GLOSSARY

## مصطلحات النظام

| المصطلح | الشرح |
|---|---|
| **Paper Trading** | تداول افتراضي بالكامل: فتح وإدارة وإغلاق صفقات وهمية بأسعار حقيقية، دون أي أمر حقيقي للوسيط |
| **Hybrid Decision Engine / Router** | المحرك المركزي الوحيد المخول باختيار المدرسة التي ستفتح الصفقة التالية |
| **School / Strategy Module** | مدرسة تداول (SMC، Wyckoff...) — وحدة برمجية مستقلة تنتج تقييمات ولا تفتح صفقات |
| **Market Snapshot** | لقطة مجمّعة لحالة السوق (اتجاه/تقلب/نشاط/سيولة proxy/بنية/جلسة) مرتبطة بوقت UTC |
| **StrategyEvaluation** | ناتج تقييم مدرسة: الحالة، الاتجاه، الشروط الناجحة/الفاشلة بقيَمها، ودرجات منفصلة |
| **RouterDecision** | قرار المحرك الهجين: المرشحون المرتّبون، الأهلية، المختار أو سبب NO_TRADE |
| **Opportunity Key** | مفتاح فريد للفرصة يمنع تنفيذ الإشارة نفسها مرتين (خلال الجلسة أو بعد إعادة التشغيل) |
| **Shadow Tracking** | تتبع الفرص المرفوضة بنفس قواعد الدخول المقترحة لقياس ما فاته المحرك — خارج ربح المحفظة |
| **Audit Chain** | سجل تدقيق append-only تُربط أحداثه بسلسلة Hash كشف التلاعب |
| **Outbox** | طابور رسائل Telegram بقاعدة "مفتاح فريد" مع إعادة محاولة تراجعية |
| **Config Version** | نسخة إعدادات غير قابلة للتعديل ببصمة Hash؛ كل قرار يرتبط بنسخته |

## حالات القرار (RouterDecisionStatus)

| الحالة | المعنى |
|---|---|
| SELECTED | اختيار مدرسة لفرصة مؤهلة |
| NO_CANDIDATE | لا مدرسة أنتجت مرشحاً |
| CANDIDATE_REJECTED_BY_ROUTER | مرشحون موجودون لكنهم فشلوا بالأهلية |
| BLOCKED_BY_DATA | جودة بيانات غير صالحة |
| BLOCKED_BY_SYSTEM | إيقاف يدوي (pause) |
| BLOCKED_BY_RISK | موانع المخاطر (يُسجل في RiskDecision) |

## مصطلحات السوق والتحليل

| المصطلح | الشرح |
|---|---|
| **BOS** (Break of Structure) | كسر بنية بإغلاق جسم الشمعة خلف آخر Swing معاكس باتجاه البنية |
| **CHoCH** (Change of Character) | أول كسر ضد اتجاه آخر كسر — إشارة تغير بنية محتمل |
| **FVG** (Fair Value Gap) | فجوة سعرية من 3 شموع تُقرأ كاختلال عرض/طلب |
| **Liquidity Sweep** | تجاوز ظلي لمستوى سيولة (قمم/قيعان متساوية) ثم إغلاق داخله |
| **Order Block** | آخر شمعة معاكسة قبل حركة Displacement |
| **Displacement** | شمعة بحجم استثنائي نسبةً إلى ATR |
| **Spring / Upthrust** (Wyckoff) | اختراق وهمي لحدّ نطاق التداول ثم عودة داخله |
| **SOS / SOW** | Sign of Strength/Weakness — إغلاق خارج النطاق يصمد |
| **ATR** | متوسط المدى الحقيقي (Wilder 14) — مقياس التقلب الأساسي |
| **ADX** | مؤشر قوة الاتجاه (لا اتجاهه) — ≥ 25 تقريباً اتجاه قائم |
| **Efficiency Ratio** | صافي الحركة ÷ مسار السعر — كفاءة الاتجاه (Kaufman) |
| **z-score** | انحراف السعر عن متوسطه بوحدات الانحراف المعياري |
| **Donchian Channel** | قناة أعلى قمة/أدنى قاع لآخر N شموع |
| **MFE / MAE** | أقصى حركة لصالح الصفقة / ضدها |

## أدوار ومكونات التشغيل

| المكوّن | المسؤولية |
|---|---|
| `HybridRuntime` | المنسّق: دورة التحليل الكاملة خطوة بخطوة |
| `VirtualClock` | ساعة افتراضية للـ backtest تمنع قراءة الوقت الحقيقي |
| `ReplayProvider` | مصدر بيانات تاريخي حتمي للتشغيل والاختبار |
| `DataHealthMonitor` | مراقبة انقطاع/تقادم البيانات وإصدار التنبيهات |
| `RiskEngine` | حجم المركز وحدوده وقاطع الخسارة اليومي |
| `PaperFillEngine` | تعبئة الأسعار (Bid/Ask + انزلاق) — لا يرسل شيئاً لأي مكان |
