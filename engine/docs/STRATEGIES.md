# وثائق المدارس الست — STRATEGIES

كل مدرسة Rule-Based بالكامل: شروط قابلة للاختبار، قيم مرصودة لكل شرط،
وأسباب رفض برموز آلية. القيم كلها قابلة للضبط من `config/strategies/*.yaml`
دون لمس الكود. **المدارس لا تفتح صفقات** — تنتج تقييمات، والمحرك الهجين
وحده يختار من يدخل.

## مبادئ مشتركة (مضمّنة في القاعدة الأساسية `app/strategies/base.py`)

- كل شرط يُسجل كـ `ConditionCheck`: (المعرّف، القيمة المرصودة، المقارنة،
  الحد، نتيجة نجاح/فشل) — قرار قابل لإعادة البناء من السجل.
- لا شمعة تُستخدم قبل إغلاقها: كل الاستدعاءات تمر عبر
  `bar_service.closed_bars(tf, as_of=now)`.
- كل تقييم يحمل `opportunity_key` فريداً لمنع تكرار التنفيذ.
- سياسة إدارة الصفقة (Break-Even/Trailing) تعود للمدرسة الأصلية حتى الإغلاق.

## 1) SMC / ICT (`smc_ict` v1.0.0 — M15)

### التعريفات الحسابية المعتمدة (المفاهيم الخلافية حُسمت تعريفياً)

| المفهوم | التعريف المُنفّذ |
|---|---|
| Swing Pivot | قمة/قاع يتجاوز `left` شموع قبله و`right` بعده؛ **لا يصبح معروفاً إلا بعد إغلاق شمعة التأكيد** (`right`-th) |
| BOS | إغلاق جسم الشمعة (لا الظل) خلف آخر Swing معاكس في اتجاه البنية |
| CHoCH | أول كسر ضد اتجاه آخر كسر مسجل |
| Equal Highs/Lows | مجموعتان من Swings ضمن tolerance (نقاط أو كسر ATR) |
| Liquidity Sweep | ظل يتجاوز مستوى EQ بمقدار ≥ `0.05 ATR` ثم إغلاق داخل النطاق خلال ≤ `sweep_close_bars` |
| Displacement | شمعة جسمها ≥ `1.2 ATR` ومداها ≥ `1.5 ATR` |
| FVG | فجوة 3 شموع: `low[i+1] > high[i-1]` (صاعدة) أو العكس، بحجم ≥ `0.25 ATR` |
| Order Block | آخر شمعة معاكسة قبل Displacement؛ تُلغى بإغلاق السعر عبرها |
| Premium/Discount | موضع السعر داخل Dealing Range النشط |

### الأنماط الثلاثة المنفّذة

1. **SWEEP_REVERSAL**: كسر سيولة (Equal Lows/Highs) + رفض وإغلاق داخل النطاق.
   SL خلف ذل الكسر + buffer 0.2 ATR، TP بنسبة RR 2.0.
2. **BOS_CONTINUATION**: تتابع HH/HL (أو LH/LL) + إغلاق خلف آخر Swing على
   الشمعة الأخيرة (وليس قبلها). SL خلف المستوى المكسور.
3. **FVG_RETRACE**: اتجاه مؤكد من السياق + ارتداد لمنطقة FVG مفتوحة بنفس
   الاتجاه. الدخول منتصف المنطقة، SL خلفها.

شرط قبول عام: RR ≥ 1.5 وإلا يبقى التقييم `ARMED` (مراقبة دون دخول).

### ما لم يُنفّذ ومَتى

مفاهيم "Order Blocks بالمعنى المؤسسي" و"ITD/IPDA data ranges" لا تُقاس من
بيانات وسيط واحد؛ بُنيت البدائل القابلة للقياس أعلاه، والـ OB يُستخدم ضمن
وصف الحالة لا كشرط دخول مستقل — توثيق صريح في `describe_capabilities()`.

## 2) Wyckoff (`wyckoff` v1.0.0 — M15)

| المفهوم | التعريف |
|---|---|
| Trading Range | قوس بين أقصى 4 Swings علوياً وأدناها؛ يشترط ≥ 20 شمعة داخلية وعرض ≥ 4 ATR و≥ 4 لمسات للحدود |
| Spring | نزول تحت قاع النطاق ≥ 0.1 ATR ثم إغلاق داخل النطاق |
| Upthrust | صعود فوق قمة النطاق ≥ 0.1 ATR ثم إغلاق داخله |
| SOS/SOW | إغلاق خارج النطاق يصمد ≥ 3 شموع |
| Phase (A–E) | **تقدير** من تسلسل الأحداث (Spring/Upthrust/SOS/SOW + حجم النشاط)؛ يُسجل كـ `estimated_phase` بثقة، وليس حقيقة |

الدخول يتطلب **حدثاً مستقلاً** (Spring/Upthrust/SOS/SOW) — المرحلة وحدها
لا تكفي. الهدف داخل النطاق المقابل (وليس رقماً اعتباطياً) مع inset 0.3 ATR.

## 3) Trend Following (`trend_following` v1.0.0 — M15)

- فلتر الاتجاه: ADX ≥ 22 + Efficiency Ratio ≥ 0.30 + محاذاة MA20/MA50.
- **DONCHIAN_BREAKOUT**: إغلاق خلف قناة Donchian(20) محسوبة على الشموع
  *قبل* الحالية، في اتجاه الاتجاه.
- **TREND_PULLBACK_CONTINUATION**: ارتداد لقرب EMA21 (≤ 0.5 ATR) خلال آخر
  5 شموع ثم شمعة استئناف مغلقة بالاتجاه.
- الخروج: **ATR Trailing (2.0 ATR) بدون TP ثابت** — النمط مبني للدخول في
  اتجاه ممتد (Trailing هو سياسة الخروج الموثقة). Break-even عند 1R.

## 4) Mean Reversion (`mean_reversion` v1.0.0 — M5)

شروط مترتبة (واحد لا يكفي):
1. **فلتر النظام**: ADX ≤ 30 (خطر الاستمرار منخفض).
2. **الانحراف**: |z-score(20)| ≥ 2.0.
3. **التأكيد**: شمعة رفض مغلقة نحو المتوسط (شرط إلزامي — RSI وحده لا يدخل
   أبداً؛ يُستخدم كمرجع مساعد فقط).
4. **الإبطال**: SL خلف أقصى الانحراف + 0.25 ATR.
- **الهدف**: المتوسط المتحرك نفسه (متوسط 20) — هدف قابل للقياس لا رقم ثابت.

---

## 5) Breakout (`breakout` v1.0.0 — M15)

- **CLOSE_BREAKOUT**: انضغاط (مدى آخر 12 شمعة ≤ 3 ATR) ثم إغلاق خلف صندوق
  الانضغاط.
- **BREAKOUT_RETEST**: كسر Donchian خلال آخر 5 شموع + عودة تلامس المستوى
  (≤ 0.3 ATR) + شمعة إغلاق تحافظ على الجانب.
- حارسان إلزاميان: **امتداد الدخول** ≤ 2.5 ATR عن المستوى (منع الدخول
  المتأخر جداً) و**السبريد** ≤ 60 نقطة عند الإشارة.

---

## 6) Order Flow / Auction (`order_flow` v1.0.0 — معطّلة)

**الحالة: `DISABLED_DATA_UNAVAILABLE`.** الذهب الفوري OTC بلا كتاب أوامر
موحد، وحجم التِكات عند وسيط واحد لا يقيس Delta/Depth — والنظام لا يزوّر
بيانات حجم. الوحدة مكتملة البنية مع واجهة `OrderFlowDataProvider` جاهزة
لربط مصدر حقيقي (عقود COMEX GC مثلاً)، وتفعيلها لا يتطلب سوى ملف Provider
جديد + `enabled: true`. تعطيلها لا يُعد خطأ صحة للنظام (مفحوص باختبار).

## إدارة الصفقات حسب المدرسة

| المدرسة | Break-Even | خروج |
|---|---|---|
| SMC/ICT | عند 1R | TP ثابت |
| Wyckoff | عند 1R | TP داخل النطاق |
| Trend | عند 1R | ATR Trailing 2.0 |
| MeanReversion | عند 1R | هدف المتوسط |
| Breakout | عند 1R | TP ثابت |

قاعدة عامة في المحرك: نقل SL يسمح **بالتضييق فقط** — إطلاقاً لا التوسيع.
