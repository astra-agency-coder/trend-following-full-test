# دليل إعداد بوت Telegram — TELEGRAM_SETUP

## 1) إنشاء البوت

1. افتح [@BotFather](https://t.me/BotFather) وأرسل `/newbot`.
2. اختر اسماً ومعرّفاً، واحفظ **التوكن** (`123456:ABC-...`).
3. (اختياري) أرسل `/setcommands` واختر بوتك وألصق:
   ```
   status - حالة النظام
   market - آخر حالة سوق
   open - الصفقات المفتوحة
   today - ملخص اليوم
   week - التقرير الأسبوعي
   performance - الإحصائيات
   strategies - حالة المدارس
   decision - آخر قرار Router
   health - صحة المكونات
   logs - آخر الأحداث
   pause - إيقاف فتح صفقات جديدة
   resume - استئناف فتح الصفقات
   ```

## 2) الحصول على معرّفاتك الرقمية

- أرسل رسالة لبوتك الجديد، ثم افتح:
  `https://api.telegram.org/bot<TOKEN>/getUpdates`
- خذ `message.from.id` (مستخدمك) و`message.chat.id` (المحادثة).
- لا تعتمد أبداً على اسم المستخدم — التفويض يتم بالمعرّف الرقمي فقط.

## 3) الإعداد

في `.env`:

```ini
TELEGRAM_ENABLED=true
TELEGRAM_BOT_TOKEN=123456:ABC-xxxx
TELEGRAM_ALLOWED_USER_IDS=111111111
TELEGRAM_ALLOWED_CHAT_IDS=111111111
```

الأسرار تأتي من متغيرات البيئة فقط — لا توكن داخل الكود أو ملفات
الـ config (النظام يمسح الأسرار من السجلات أيضاً).

## 4) ماذا سيصلك

| النوع | مثال المحتوى |
|---|---|
| بدء/توقف النظام | إصدار، حالة MT5/DB، حالة كل مدرسة |
| انقطاع/استعادة البيانات | السبب وعمر آخر tick |
| تغير حالة السوق | الاتجاه/التقلب/الجلسة قبل وبعد |
| فتح صفقة | الاتجاه، المدرسة، النمط، الدخول/SL/TP، الحجم، المخاطرة، السبريد، سياق السوق، سبب الاختيار |
| إغلاق صفقة | سبب الإغلاق، الأسعار، الربح الصافي، R multiple، العمولات |
| تقارير يومية/أسبوعية | المقاييس + أكثر أسباب عدم التداول |
| أخطاء النظام | المكوّن والرسالة |

كل رسالة تحمل معرّفات قابلة للبحث (Trade ID / Decision ID) — وليس مجرد
BUY/SELL.

## 5) الحماية

- التفويض: قائمة بيضاء بالمعرّف الرقمي + حد معدل (20 أمر/دقيقة افتراضياً).
- كل أمر إداري يُسجل في سجل التدقيق (`TELEGRAM_COMMAND`).
- الأوامر تشغيلية فقط (استعلام/pause/resume) — لا توجد أوامر Buy/Sell/Close.
- الرسائل تمر عبر Outbox بقاعدة "مفتاح رسالة فريد" فلا تتكرر التنبيهات،
  مع إعادة محاولة تراجعية (5 محاولات: 1/5/15/60/240 دقيقة).
- إن كان `TELEGRAM_ENABLED=false` يعمل النظام كاملاً بلا إشعارات (وضع CI).

## ملاحظات

- البوت يستخدم long polling — لا يحتاج IP ثابت أو شهادات.
- `pause` يوقف فتح صفقات جديدة فقط؛ الصفقات المفتوحة تبقى تحت إدارة مدارسها.
- `resume` يرفض إذا كانت جودة البيانات غير صالحة.
